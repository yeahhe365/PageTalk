## Overview

A Chrome extension that brings seamless speech-to-text input to web pages.

## Features

- Realtime speech input on web pages.
- Audio file transcription.
- Configurable ASR API.
- Built for Chrome extension workflows.

## Quick Start

- Enter `pagetalk`.
- Run `npm install`.
- Run `npm run build`.
- Load the build output or source directory from Chrome extension management.

## Configuration

- Set the ASR endpoint, API key, and transcription options in extension settings.
